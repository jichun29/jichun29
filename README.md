**GlassTV（玻璃桌面）** —— 给电视一块干净的玻璃桌面。没有广告位，没有推荐流，只有你的 App、你选的壁纸和时钟屏保。基于开源的 CleanYourTV 深度定制，小米国行电视实测可用。

> 提供通用版（Android 5.0+）与 4.4 精简版两个安装包。
